## 📚 Основные классы (Java) на турнире

### 🔧 Железо (Studica)
*   `Titan` — главный контроллер моторов (создается `new Titan(42)`).
*   `Titan.Motor` — управление конкретным мотором (`getMotor(0)`).
*   `Titan.Encoder` — чтение данных с энкодера (`getEncoder(0, 1.0)`).

### 🎮 Управление и математика (WPILib)
*   `XboxController` — чтение сигналов с геймпада.
*   `MecanumDriveKinematics` — математика для меканум-колёс (переводит движение робота в скорости колёс).
*   `ChassisSpeeds` — задает скорость робота (вперёд, вбок, поворот).
*   `MecanumDriveWheelSpeeds` — получает готовые скорости для каждого из 4 моторов.

### 🤖 Для автономки и точности (Опционально)
*   `MecanumDriveOdometry` — подсчет положения робота на поле.
*   `PIDController` — точная корректировка скорости/позиции (если понадобится).
