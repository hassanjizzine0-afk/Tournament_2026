## 📚 Основные классы (Java) на турнире

### 🔧 Железо (Библиотека Studica)
*Это отдельная библиотека, которую вы устанавливаете дополнительно (через Vendor Library в VS Code). Она нужна только для того, чтобы «подружить» WPILib с конкретным железом Studica.*
*   `Titan` — главный контроллер моторов (создается `new Titan(42)`).
*   `Titan.Motor` — управление конкретным мотором (`getMotor(0)`).
*   `Titan.Encoder` — чтение данных с энкодера (`getEncoder(0, 1.0)`).

### 🎮 Управление и математика (WPILib)
*Это стандартные классы фреймворка FIRST, которые уже «вшиты» в WPILib. WPILib — это фреймворк, созданный специально для соревнований FRC (FIRST Robotics Competition). Изначально он разрабатывался для работы на контроллерах **roboRIO** (главный мозг робота в FRC), но благодаря своей гибкости успешно работает и на других платформах, таких как наш **Studica VMX**. Эти классы не зависят от Studica и работают с любым железом.*
*   `XboxController` — чтение сигналов с геймпада.
*   `MecanumDriveKinematics` — математика для меканум-колёс (переводит движение робота в скорости колёс).
*   `ChassisSpeeds` — задает скорость робота (вперёд, вбок, поворот).
*   `MecanumDriveWheelSpeeds` — получает готовые скорости для каждого из 4 моторов.

### 🤖 Для автономки и точности (WPILib — Опционально)
*   `MecanumDriveOdometry` — подсчет положения робота на поле.
*   `PIDController` — точная корректировка скорости/позиции (если понадобится).
