# Studica VMX Robotics Controller

VMX — это «мозг» робота на базе Linux. Он отвечает за связь с пультом, обработку логики и обмен данными с контроллером моторов Titan по шине CAN [citation:1][citation:3].

## 📊 Основные характеристики (Electrical Specifications)

| Параметр | Значение |
| :--- | :--- |
| **Входное напряжение** | 6–16V DC [citation:1] |
| **Выходное напряжение** | 5V, 3.3V [citation:1] |
| **Интерфейсы связи** | USB, I2C, SPI, CAN, UART [citation:1] |
| **Разъем питания** | 2-Pin JST VH [citation:1] |
| **USB разъем** | USB Micro-B [citation:1] |
| **Поддерживаемые языки** | Java, C++, Python, ROS, LabVIEW [citation:1][citation:14] |

## 🧭 Характеристики IMU (Встроенный гироскоп/акселерометр)
*   **Время калибровки при старте:** 15 секунд (в это время плату нельзя двигать) [citation:1]
*   **Чувствительность гироскопа:** +/- 2000 °/сек [citation:1]
*   **Чувствительность акселерометра:** +/- 2 g [citation:1]

## 🔌 Спецификации портов ввода/вывода

### Аналоговые входы (Analog Input)
| Параметр | Значение |
| :--- | :--- |
| **Количество каналов** | 4 [citation:1] |
| **Разрешение** | 12 бит [citation:1] |

### Цифровые входы/выходы (Digital IO)
| Параметр | Значение |
| :--- | :--- |
| **Всего каналов** | 30 [citation:1] |
| **Входы / Прерывания** | 25 каналов [citation:1] |
| **Выходы / PWM** | 27 каналов [citation:1] |
| **Аппаратные энкодеры** | 5 пар каналов [citation:1] |

### Цифровая связь (Digital Communication)
| Протокол | Скорость |
| :--- | :--- |
| **CAN (2.0b)** | 1 Mbps [citation:1] |
| **SPI** | 8 MHz [citation:1] |
| **I2C** | 400 kHz [citation:1] |
| **USB** | 12 Mbps [citation:1] |
| **UART** | 115 kbps [citation:1] |

## 🌐 Сетевые настройки (по умолчанию)
*   **Ethernet (рекомендуется):** IP-адрес `172.22.11.2` [citation:2]
*   **Wi-Fi (режим точки доступа):** Имя сети (SSID) `VMX-1234`, пароль `password` [citation:2]

# Распиновка контроллера Studica Titan

| Callout | Name | What it’s for | Notes |
| :---: | :--- | :--- | :--- |
| **1** | Main Power Input | Основной вход питания Titan. | Используйте любой из входов; оба соединены параллельно. |
| **2** | External Outputs | Сквозные выходы с тем же напряжением, что и на основном входе. | Обычно используются для питания внешних устройств с тем же напряжением. |
| **3** | Reset button | Кнопка сброса Titan. | — |
| **4** | Status LED | Индикация состояния контроллера. | Подробнее см. на странице статусных светодиодов. |
| **5** | USB (Titan) | Программирование / обновление прошивки / диагностика. | USB-подключение к главному контроллеру. |
| **6** | Debug header | Только для внутреннего использования. | Не предназначен для подключения пользователем. |
| **7** | CAN 2.0B header | CAN-связь. | Имеет впаянный терминальный резистор. |
| **8** | Motor 1 output | Выход питания для мотора канала 1. | — |
| **9** | Motor 0 output | Выход питания для мотора канала 0. | — |
| **10** | Motor 1 encoder/limit | Энкодер + концевой выключатель для мотора 1. | — |
| **11** | Boot button | Доступ к загрузчику / режиму восстановления. | Используется для восстановления прошивки (см. страницу обновления прошивки). |
| **12** | Motor 0 encoder/limit | Энкодер + концевой выключатель для мотора 0. | — |
| **13** | RGB LED ports | Выходы для RGB-светодиодов. | Управляются встроенным LED-контроллером. |
| **14** | LED controller reset | Сброс LED-контроллера. | — |
| **15** | I2C port (LED controller) | I2C-связь для LED-контроллера. | Уровень напряжения — 5В. |
| **16** | LED controller USB | Программирование LED-контроллера. | Отдельно от USB-порта Titan. |
| **17** | Motor 2 encoder/limit | Энкодер + концевой выключатель для мотора 2. | — |
| **18** | Motor 3 encoder/limit | Энкодер + концевой выключатель для мотора 3. | — |
| **19** | Motor 2 output | Выход питания для мотора канала 2. | — |
| **20** | Motor 3 output | Выход питания для мотора канала 3. | — |
| **21** | Fuse holders | Расположение предохранителей каналов / системы. | Используйте только предохранители указанного типа/номинала. |
